# Evaluation of Information Retrieval Models and Query Expansion on the TREC AP 88-90 Collection

**Loyer, Dominique S; Loyer, Dominique**

## Abstract

This report details the implementation and
comparative evaluation of a monolingual in-
formation retrieval (IR) system on the standard
TREC Associated Press (AP) 88-90 collection.
We studied the influence of text preprocessing
(Porter stemming vs. baseline), query length
(short vs. long), and the weighting model
(QLD vs. BM25). The system was devel-
oped in Python with Pyserini under Java 21.
The best-identified base configuration (Base-
line, Long Queries, BM25) achieved a MAP of
0.2205. Stemming proved to be less effective
than the baseline (max MAP of 0.1778). An en-
hancement technique using pseudo-relevance
feedback, RM3, applied to the best baseline
configuration, achieved a final MAP of 0.2948,
demonstrating a significant relative improve-
ment (+34)
