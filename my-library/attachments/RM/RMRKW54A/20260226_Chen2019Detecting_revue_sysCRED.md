## Abstract
L'article "Detecting Media Bias using Gaussian Mixture Models: An Unsupervised Approach" de Chen et Oh (2019) propose une approche non supervisée pour détecter les biais médiatiques en utilisant des modèles de mélange gaussien. Cette méthode vise à identifier les biais dans les reportages médiatiques sans nécessiter de données étiquetées.

## Contribution principale
La contribution principale de cet article est l'utilisation de modèles de mélange gaussien pour détecter les biais médiatiques de manière non supervisée, ce qui constitue une approche innovante par rapport aux méthodes traditionnelles qui nécessitent des données étiquetées pour l'apprentissage.

## Méthodologie
La méthodologie utilisée dans cet article implique l'application de modèles de mélange gaussien à des données de reportages médiatiques pour identifier les clusters de biais. Les auteurs utilisent des caractéristiques telles que le ton, le langage et les sujets abordés pour former les modèles de mélange gaussien.

## Résultats clés
Les résultats clés de l'étude montrent que les modèles de mélange gaussien peuvent efficacement détecter les biais médiatiques dans les reportages, même en l'absence de données étiquetées. Les auteurs démontrent également que leur approche peut identifier différents types de biais, tels que les biais politiques ou sociaux.

## Pertinence SysCRED
La pertinence de cet article pour le SysCRED (Systèmes complexes et résilience dans les données) réside dans son application de méthodes d'apprentissage automatique non supervisées pour analyser des données complexes et identifier des patterns de biais, ce qui peut être utile pour comprendre et gérer les systèmes complexes d'information dans les médias et au-delà.
