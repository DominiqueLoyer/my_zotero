## Abstract
L'article présente une étude sur l'évaluation de la crédibilité de l'information médicale en ligne, en proposant un cadre pour la création de jeux de données d'entraînement pour les modèles d'apprentissage automatique. Les auteurs visent à soutenir les chercheurs des communautés médicale et informatique dans la préparation de jeux de données pour lutter contre la désinformation médicale en ligne.

## Contribution principale
La contribution principale de cette étude est la proposition d'un processus d'annotation active pour la création de jeux de données d'entraînement pour les modèles d'apprentissage automatique. Ce processus combine l'apprentissage de représentation, le regroupement et la réévaluation pour améliorer l'efficacité de l'annotation.

## Méthodologie
La méthodologie utilisée dans cette étude consiste en une analyse qualitative des données expérimentales pour élaborer un protocole d'annotation pour les experts médicaux. Les auteurs ont également proposé un pipeline de prétraitement pour les phrases à évaluer, qui comprend l'apprentissage de représentation, le regroupement et la réévaluation.

## Résultats clés
Les résultats clés de cette étude sont la collecte de plus de 10 000 annotations de phrases liées à des sujets médicaux sélectionnés, pour un coût inférieur à 7 000 dollars américains. Les auteurs ont également développé un cadre d'annotation active pour améliorer l'efficacité de l'annotation des phrases non crédibles.

## Pertinence SysCRED
Cette étude est pertinente pour le projet SysCRED, car elle propose une approche pour évaluer la crédibilité de l'information médicale en ligne, qui est un aspect clé de la lutte contre la désinformation en santé. Les résultats de cette étude pourraient être utilisés pour améliorer les capacités de détection de la désinformation médicale en ligne et pour soutenir les chercheurs dans la création de jeux de données d'entraînement pour les modèles d'apprentissage automatique.
