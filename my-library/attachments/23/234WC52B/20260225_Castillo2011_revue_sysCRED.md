# Castillo2011
- **Titre:** Information Credibility on Twitter

## Abstract
This seminal paper investigates the multifaceted problem of information credibility on Twitter by exploring various features derived from messages, users, and diffusion patterns. It aims to develop a computational understanding of how trustworthiness is perceived and can be assessed within the microblogging platform. The research provides foundational insights into the characteristics distinguishing credible from non-credible information.

## Contribution principale
- Pioneering work in identifying and categorizing a comprehensive set of features for information credibility assessment on Twitter (e.g., source, content, and propagation features).
- Development of early machine learning models to predict information credibility based on these extracted features.
- Laying crucial groundwork for subsequent research in mis/disinformation detection and credibility evaluation on social media platforms.

## Méthodologie
The study typically involved collecting a large dataset of tweets, which were often manually labeled for credibility or factuality. Various features related to the tweet's content (e.g., presence of URLs, hashtags), the user posting it (e.g., number of followers, verified status), and its propagation pattern (e.g., retweets, replies) were extracted. These features were then used to train and evaluate supervised machine learning models (e.g., decision trees, support vector machines) to classify information credibility.

## Résultats clés
- Demonstrated that a combination of features from messages, sources, and propagation patterns is crucial for effective credibility assessment on Twitter.
- Identified specific features, such as the number of URLs in a tweet, user's follower count, and retweet activity, as strong indicators of perceived credibility.
- Showed that machine learning models can achieve reasonable accuracy in distinguishing credible from non-credible information, highlighting the predictive power of computational features.

## Pertinence SysCRED
Ce travail est fondamental pour SysCRED car il aborde directement la détection et l'évaluation de la crédibilité de l'information, un pilier de la recherche sur la *crédibilité systémique*. Les caractéristiques identifiées (source, contenu, propagation) peuvent être modélisées dans des **ontologies** pour structurer formellement les connaissances sur les facteurs de crédibilité. L'intégration de ces caractéristiques explicites (symboliques) avec des patterns extraits de données massives (neuronaux) est un point de convergence pour l'**IA neuro-symbolique**, permettant des systèmes plus robustes, explicables et évolutifs pour évaluer la crédibilité dans des contextes dynamiques.
