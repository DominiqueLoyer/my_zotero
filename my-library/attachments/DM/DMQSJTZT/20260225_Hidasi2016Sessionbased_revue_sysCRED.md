# Hidasi2016Sessionbased

## Abstract
L'article présente une approche de recommandation basée sur les sessions en utilisant les réseaux neuronaux récurrents (RNN) pour améliorer la précision des recommandations dans les systèmes de recommandation en ligne.

## Contribution principale
La contribution principale de l'article est de proposer une approche RNN pour les recommandations basées sur les sessions, qui prend en compte l'ensemble de la session pour fournir des recommandations plus précises, plutôt que de se baser uniquement sur les dernières interactions de l'utilisateur.

## Méthodologie
La méthodologie utilisée consiste à appliquer les RNN sur des données de sessions pour prédire les prochaines interactions de l'utilisateur. Les auteurs proposent également des modifications aux RNN classiques, telles que l'utilisation d'une fonction de perte de classement pour améliorer la viabilité de l'approche pour ce problème spécifique.

## Résultats clés
Les résultats expérimentaux sur deux jeux de données montrent des améliorations significatives par rapport aux approches couramment utilisées, démontrant l'efficacité de l'approche RNN pour les recommandations basées sur les sessions.

## Pertinence SysCRED
L'article est pertinent pour le domaine du SysCRED car il aborde le problème de la recommandation basée sur les sessions, qui est un défi courant dans les systèmes de recommandation en ligne. Les résultats de l'article pourraient être appliqués pour améliorer la précision des recommandations dans les systèmes de recommandation en ligne, ce qui est un objectif clé du SysCRED.
