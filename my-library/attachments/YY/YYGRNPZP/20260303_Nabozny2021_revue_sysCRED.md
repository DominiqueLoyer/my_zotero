- **Titre:** Active Annotation in Evaluating the Credibility of Web-Based Medical Information: Guidelines for Creating Training Data Sets for Machine Learning

## Abstract
L'article présente une étude sur l'évaluation de la crédibilité de l'information médicale en ligne, en proposant un cadre pour la création de jeux de données d'entraînement pour les modèles d'apprentissage automatique. Les auteurs visent à lutter contre la désinformation médicale en ligne en utilisant l'apprentissage automatique.

## Contribution principale
La contribution principale de cette étude est la proposition d'un processus d'annotation active pour la création de jeux de données d'entraînement pour les modèles d'apprentissage automatique. Ce processus permet de réduire le coût et le temps nécessaire pour annoter les données, tout en améliorant la qualité des annotations.

## Méthodologie
La méthodologie utilisée dans cette étude consiste en plusieurs étapes :
* Une étude qualitative pour développer un protocole d'annotation pour les experts médicaux
* Un processus de prétraitement des données pour réduire le nombre de données à annoter
* Une annotation active des données pour améliorer la qualité des annotations

## Résultats clés
Les résultats clés de cette étude sont :
* La collecte de plus de 10 000 annotations de phrases liées à des sujets médicaux pour moins de 7 000 $
* Le développement d'un cadre d'annotation active pour améliorer l'efficacité de l'annotation des données non crédibles

## Pertinence SysCRED
Cette étude est pertinente pour le projet SysCRED car elle propose une approche pour évaluer la crédibilité de l'information médicale en ligne, ce qui est un objectif clé du projet. Les résultats de cette étude pourraient être utilisés pour améliorer la qualité des données utilisées pour entraîner les modèles d'apprentissage automatique dans le cadre du projet SysCRED.
