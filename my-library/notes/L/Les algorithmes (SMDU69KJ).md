# Les algorithmes

**Loyer S. Dominique; Loyer, Dominique**

## Abstract

Un algorithme, c’est une suite d’instructions, qui une fois exécutée correctement, conduit à un résultat donné. Commençons par le code binaire puisque que c'est tout ce qu'un ordinateur comprend Une information binaire ne peut qu'avoir deux états (ouvert ou fermé) On le symbolise par 0 ou 1. Algorithme de classification. Naive Bayes Les domaines d'application du classifieur bayésien naïf sont les suivants : traitement automatique du langage naturel, détection de spams dans vos logiciels de courrier électronique, système de recommandation d'achat, et également analyse de sentiments dans les enquêtes ou dans les commentaires d'achat d'articles.
