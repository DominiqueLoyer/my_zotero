# FPRandom: Randomizing core browser objects to break advanced device fingerprinting techniques

**Laperdrix, Pierre; Baudry, B.; Mishra, Vikas**

## Abstract

S2 TL;DR: FPRandom is presented, a modified version of Firefox that adds randomness to mitigate the most recent fingerprinting algorithms, namely canvas fingerprinting, AudioContext fingerprinting and the unmasking of browsers through the order of JavaScript properties.
