# User tracking on the web via cross-browser fingerprinting

**Boda, Károly; Földes, Á.; Gulyás, G.; Imre, S.**

## Abstract

S2 TL;DR: It is shown that a part of the IP address, the availability of a specific font set, the time zone, and the screen resolution are enough to uniquely identify most users of the five most popular web browsers, and that user agent strings are fairly effective but fragile identifiers of a browser instance.
