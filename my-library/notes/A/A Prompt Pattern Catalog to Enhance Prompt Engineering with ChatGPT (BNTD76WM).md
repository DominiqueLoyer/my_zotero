# A Prompt Pattern Catalog to Enhance Prompt Engineering with ChatGPT

**White, Jules; Fu, Quchen; Hays, Sam; Sandborn, Michael; Olea, Carlos; Gilbert, Henry; Elnashar, Ashraf; Spencer-Smith, Jesse; Schmidt, Douglas C.**

## Abstract

Prompt engineering is an increasingly important skill set needed to converse effectively with large language models (LLMs), such as ChatGPT. Prompts are instructions given to an LLM to enforce rules, automate processes, and ensure speciﬁc qualities (and quantities) of generated output. Prompts are also a form of programming that can customize the outputs and interactions with an LLM.
