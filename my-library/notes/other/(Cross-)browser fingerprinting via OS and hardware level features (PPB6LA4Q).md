# (Cross-)browser fingerprinting via OS and hardware level features

**Cao, Yinzhi; Li, Song; Wijmans, Erik**

## Abstract

In this paper, we propose a browser fingerprinting technique that can track users not only within a single browser but also across different browsers on the same machine. Specifically, our approach utilizes many novel OS and hardware level features, such as those from graphics cards, CPU, and installed writing scripts.
